# PROMPT

Desenvolva o design completo de um sistema SaaS corporativo chamado **TalentFlow**, especializado em Gestão de Talentos, Recursos Humanos, Performance, Competências e Desenvolvimento Organizacional.

O sistema deve transmitir a sensação de um software utilizado por grandes empresas multinacionais.

O visual deve ser extremamente moderno, minimalista, elegante e profissional.

Não utilizar aparência de sistema escolar ou projeto acadêmico.

Inspirar-se em:

* Workday
* SAP SuccessFactors
* Microsoft Dynamics 365
* Monday.com
* Linear
* ClickUp
* Notion
* Jira Cloud
* Atlassian
* Stripe Dashboard
* Vercel Dashboard

Utilizar um Design System consistente baseado em componentes reutilizáveis.
